# oracle-free-vm（Go）

在本機用 **OCI CLI** 排程／輪詢試開 Oracle Always Free 實例。本專案提供兩個二進位：

| 二進位 | 用途 |
|--------|------|
| `oracle-free-setup` | 互動式（繁中選單）：偵測/安裝 CLI、編輯艦隊計畫、選間隔、寫入 `fleet-plan.txt`、安裝排程 |
| `oracle-free-camp` | 非互動：讀 `.env` + `fleet-plan.txt`，對缺少的計畫項目呼叫 `oci` 試開機 |

- **不會**內嵌 API 私鑰或 SSH 私鑰；只呼叫本機 `oci` CLI
- boot 容量合計上限 **200 GB**（Always Free）
- Shape 僅允許：`VM.Standard.E2.1.Micro` 或 `VM.Standard.A1.Flex`（固定 2 OCPU / 12GB）

## 建置

```bash
cd oracle-free-vm
go build -o oracle-free-setup ./cmd/setup
go build -o oracle-free-camp ./cmd/camp
```

兩個二進位建議放在同一目錄；`setup` 預設會找旁邊的 `oracle-free-camp`。

## 第一部分：設定精靈（setup）

```bash
./oracle-free-setup
```

流程：

1. 偵測 OS（darwin / linux / windows），確認 `oci --version`；沒有則依平台指引安裝
2. 艦隊計畫 CRUD（新增／刪除／修改）：名稱、shape、boot_gb；合計 boot ≤ 200
3. 選擇間隔：15m / 30m / 1h / 12h / 24h
4. 寫入工作目錄的 `fleet-plan.txt`（可用 `ORACLE_FREE_VM_DIR` 覆寫目錄）
5. 安裝排程  
   - Unix：`crontab` + `CRON_TZ=Asia/Taipei`  
   - Windows：`schtasks` 或產生 `.ps1` + 說明
6. 印出如何填 `.env` 與 `~/.oci/config` `[DEFAULT]`

選用選單：**終止線上實例**（兩次確認後才呼叫 `oci compute instance terminate`）。

## 第二部分：露營一輪（camp）

```bash
cp .env.example .env   # 填入 compartment / subnet 等
# 確認 fleet-plan.txt 已由 setup 產生
./oracle-free-camp
```

環境變數（`.env` 或程序環境）：

| 變數 | 必填 | 說明 |
|------|------|------|
| `OCI_COMPARTMENT_ID` | ✓ | compartment OCID |
| `OCI_SUBNET_ID` | ✓ | subnet OCID |
| `OCI_REGION` | | 預設 `ap-singapore-1` |
| `OCI_CLI_PROFILE` | | 預設 `DEFAULT` |
| `OCI_AVAILABILITY_DOMAIN` | | 空白則自動取第一個 |
| `SSH_PUBLIC_KEY_FILE` | ✓ | 機器 SSH public key 檔路徑（無預設，須自行填） |
| `OCI_IMAGE_AMD` / `OCI_IMAGE_ARM` | | 空白則自動挑 Ubuntu 24.04 Minimal |
| `ORACLE_FREE_VM_DIR` | | `.env` 與 `fleet-plan.txt` 所在目錄（預設 cwd） |

行為：

- 列出 RUNNING + PROVISIONING；計畫中缺的才 launch
- 映像：Ubuntu 24.04 Minimal（免費平台映像）；A1 帶 shape-config；指派 public IP
- 容量不足 / 429 → 印 `FAIL` 原因
- 有成功 → `NOTIFY: created …`
- 無成功 → `quiet: no new success`

## fleet-plan.txt 格式

```
# fleet-plan.txt — generated by oracle-free-setup
interval=15m
# name|shape|ocpus|memory_gb|boot_gb
af-amd-50|VM.Standard.E2.1.Micro|||50
af-amd-100|VM.Standard.E2.1.Micro|||100
af-arm-2o12|VM.Standard.A1.Flex|2|12|50
```

Micro 的 ocpus / memory 欄位留空。

## 安全

- `.gitignore` 已排除：`.env`、`*.pem`、`.oci/`、`bin/`、`fleet-plan.txt` 等
- 允許提交：`.env.example`、`fleet-plan.example.txt`
- API Key PEM 放在本機 `~/.oci/`，勿放入本專案
